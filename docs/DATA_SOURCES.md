# Data acquisition and limits

Run `PYTHONPATH=pipeline .venv/bin/python -m jev_elections.cli fetch`. The collection module also exposes `collect(output_path, raw_dir, timeout=30, reuse_existing=True)`. The default verifies cached raw hashes and preserves acquisition timestamps; explicitly pass `reuse_existing=False` for a new acquisition. Freeze existing records before refreshing. It performs actual HTTPS requests, validates every redirect against a fixed publisher allowlist and public DNS, limits downloads to12MB (14MB for the fixed FEC2020 report), and never uses credentials or proxies. This fixed-source collector is not a general URL proxy and does not claim DNS-rebinding protection against arbitrary hostile servers. PDF parsing requires Poppler's `pdftotext`.

Each successful response has a SHA-256 addressed local raw file, acquisition ID, actual UTC retrieval time, media type, status, final URL and parser version. `data/registry/collection_report.json` records failures as well as successes. Raw bodies are ignored by Git; public facts are in `data/processed/dataset.json`. All publication dates lacking a substantiated clock time stay day-precision inside the observation value, with `published_at=null`. Availability is conservatively the actual acquisition time, never a backdated midnight. Recollection creates new acquisition records; preserve a frozen snapshot before updating the working dataset.

## Rights and publication

Rights flags apply only to the exact independently worded factual records/numeric extracts defined by these parsers. They do not license full articles, PDFs, images, transcripts or recordings. Full responses remain local and must not be pushed to Git LFS merely because they are publicly readable. Source records preserve publisher attribution, original links, the factual-extract rights basis and any applicable reuse-policy link. Census factual geography is federal government data. State ballot extracts contain public candidate/contest facts only. Texas Tribune permits article republication under its [guidelines](https://www.texastribune.org/republishing-guidelines/), but this project publishes original factual records instead of its article text or photos. Unknown Engagious reuse rights exclude it from public model inputs.

## Expansion gates

Add a source to the allowlist only after verifying its primary publisher URL. Acquire and preserve the actual response; implement a fail-closed parser with offline tests. Verify every ballot candidate and write-in policy independently of the poll. House geography requires the election's actual district boundaries, not just a state FIPS code or previous Congress's map. Require a dated eligible rating, a current qualifying poll and independent race-specific qualitative record before admitting an expanded core experiment race. Missing evidence stays missing. Focus groups require verified session/transcript anchors, recruitment, format, date, geography and rights; statewide evidence must not masquerade as district evidence.
