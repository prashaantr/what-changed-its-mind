# Map geography

`states-albers-10m.json` is copied unchanged from us-atlas 3.0.1, by Mike Bostock.
Source: https://github.com/topojson/us-atlas
License: ISC; see LICENSE-us-atlas.txt alongside this file.
The package derives boundaries from the US Census Bureau. These are US state boundaries, NOT congressional district boundaries. House races are explicitly located at state level in the interface until district geometry is separately verified.

The frontend uses the preprojected Albers USA geometry without substituting decorative or invented shapes.
